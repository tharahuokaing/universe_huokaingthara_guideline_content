## 🎯 About the Module / អំពីម៉ូឌុល

**`universe_huokaingthara_guideline_content`** defines the official content creation, copyright protection, commercial advertising, and cybersecurity standards for **UNIVERSE HUOKAING THARA Group**. It helps production crews, actors, scriptwriters, marketing partners, and developers maintain brand consistency and legal compliance across all releases.

## ✨ Key Features / លក្ខណៈពិសេសចម្បង

* **🔎 Real-Time Rule Search & Filtering:** Filter policy cards by category (*Production, Copyright, Advertising, Cybersecurity*) or search by keyword in real time.
* **✅ Interactive Pre-Publish Checklist:** Track verification progress (`0/4` to `4/4 Verified`) with a dynamic progress bar and a completion readiness banner before publishing content or code.
* **🌐 Dual Language Switcher (Khmer / English):** Instant toggle supporting Khmer-only, English-only, or bilingual display modes.
* **🌙 Dark / Light Cyberpunk Theme:** Styled with the signature **UNIVERSE HUOKAING THARA** holographic scanline aesthetic and adaptive theme switching.

## 🛠️ Tech Stack & Architecture / បច្ចេកវិទ្យាប្រើប្រាស់

- **Frontend Core:** Semantic HTML5, CSS3 (CSS Grid, Flexbox, Custom Properties), Vanilla JavaScript (ES6+)
- **Typography:** Google Fonts (`Kantumruy Pro` for Khmer script, `Poppins` for English UI)
- **Icons:** FontAwesome v6.4.0
- **UI/UX Design:** Cyberpunk Holographic Dark/Light Theme with Scanline Overlay
